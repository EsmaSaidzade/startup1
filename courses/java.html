Lesson 1: Introduction to Java

Java is a popular programming language used to create applications, websites, desktop programs and Android apps. It is an object-oriented programming language.

What is a Java program?

A Java program contains instructions that tell the computer what to do. A simple Java program looks like this: 

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}

System.out.println() displays text in the output. The main method is where a simple Java program starts running.

Variables and Data Types

Variables store information. Java requires us to specify the data type of a variable. 

int age = 20;
double price = 12.5;
String name = "Alex";
boolean isStudent = true;

Lesson 2: Conditions, Loops and Arrays

Conditions

Conditions allow a program to make decisions. The if and else statements execute different instructions depending on whether a condition is true or false. 

int age = 20;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Not an adult");
}

Loops

Loops repeat instructions. Java has different types of loops, including for and while. 

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

This loop prints numbers from 1 to 5.

Arrays

An array stores multiple values of the same data type in one variable. 

int[] numbers = {10, 20, 30, 40};

System.out.println(numbers[0]);

Array positions start at 0. Therefore, numbers[0] gives 10.

Lesson 3: Methods and Classes

Methods

A method is a block of code that performs a particular task. Methods help us organize and reuse code. 

public static void greet() {
    System.out.println("Welcome to Java!");
}

public static void main(String[] args) {
    greet();
}

Parameters

Parameters allow us to send information to a method. 

public static void greet(String name) {
    System.out.println("Hello " + name);
}

Classes and Objects

A class is a blueprint used to create objects. Objects can have their own data and behavior. 

class Student {
    String name;
    int age;
}

Here, Student is a class with two variables: name and age.
