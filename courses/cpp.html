Lesson 1: Introduction to C++

C++ is a general-purpose programming language. It is used in software development, games, operating systems and applications where performance is important.

Your First C++ Program

A C++ program can display a message using cout. 

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!";
    return 0;
}

#include <iostream> allows us to use input and output features. cout displays information on the screen. The main() function is where the program starts.

Variables and Data Types

Variables store information. Every variable has a data type. 

int age = 20;
double price = 12.5;
char grade = 'A';
string name = "Alex";
bool isStudent = true;

Lesson 2: Conditions, Loops and Arrays

Conditions

Conditions allow a program to make decisions. The if and else statements execute different instructions depending on whether a condition is true or false. 

int age = 20;

if (age >= 18) {
    cout << "Adult";
} else {
    cout << "Not an adult";
}

Loops

Loops repeat instructions. A for loop is useful when we know how many times we want to repeat something. 

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}

This loop prints numbers from 1 to 5. The endl command moves the output to a new line.

Arrays

An array stores multiple values of the same data type in one variable. 

int numbers[] = {10, 20, 30, 40};

cout << numbers[0];

Array positions start at 0. Therefore, numbers[0] gives 10.

Lesson 3: Functions and Classes

Functions

A function is a block of code that performs a particular task. Functions help us organize and reuse code. 

void greet() {
    cout << "Welcome to C++!";
}

int main() {
    greet();
    return 0;
}

Parameters

Parameters allow us to send information to a function. 

void greet(string name) {
    cout << "Hello " << name;
}

Classes and Objects

A class is a blueprint used to create objects. Objects can have their own data and behavior. 

class Student {
public:
    string name;
    int age;
};

Here, Student is a class with two variables: name and age.
