About This Course

HTML stands for HyperText Markup Language. It is the standard language used to create and structure web pages.

In this beginner-friendly course, you will learn how to create headings, paragraphs, links, images, lists and forms. No previous HTML knowledge is required.

Level: Beginner

What you need: A computer and a code editor such as VS Code.

Lesson 1: Introduction to HTML

Discover what HTML is, how it works and how to create your first HTML document.

Topics:

  • What is HTML?
  • HTML document structure
  • Opening and closing tags
  • Headings and paragraphs

  • Forms and input fields
