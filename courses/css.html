About This Course

CSS stands for Cascading Style Sheets. It is the language used to style and design HTML web pages.

In this beginner-friendly course, you will learn how to change colors, fonts, backgrounds, layouts and the overall appearance of websites.

Level: Beginner

What you need: Basic HTML knowledge and a code editor such as VS Code.

Lesson 1: Introduction to CSS

Understand how CSS works and how to connect CSS with HTML documents.

Topics:

  • What is CSS?
  • CSS syntax and selectors
  • Inline, internal and external CSS
  • Colors, fonts and text styling

  • Responsive design
  • Media queries
