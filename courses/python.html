About This Course

Python is a popular, high-level programming language known for its simple and readable syntax. It is used in web development, data science, artificial intelligence and automation.

In this beginner-friendly course, you will learn programming fundamentals and how to write your first Python programs.

Level: Beginner

What you need: A computer and Python installed, or an online Python editor.

Lesson 1: Python Basics

Learn the fundamentals of Python and understand how to write your first lines of code.

Topics:

  • What is Python?
  • Variables and data types
  • Strings, integers and floats
  • Arithmetic and comparison operators
  • Printing information with print()

Learn how to make decisions, repeat instructions and store multiple values in Python.

Topics:

  • Creating and accessing lists
  • Working with list elements

Discover how to organize your code using functions and store information using dictionaries.

Topics:

  • Creating and calling functions
  • Function parameters
  • Return values
  • Creating dictionaries
  • Accessing dictionary values
